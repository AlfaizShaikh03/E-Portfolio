# Alfaiz Shaikh | E-Portfolio

A premium, Awwwards-level single-page React portfolio showcasing my work as an **AI/ML Engineer & Cybersecurity Specialist**. Designed with an emphasis on high-performance animations, fluid UI/UX, and a dark glassmorphism aesthetic.

## 🚀 Features

- **Dynamic Interactive Background:** HTML5 Canvas particle system integrated with slow-moving CSS aurora blobs and a mouse-tracking radial glow.
- **Smooth Inertial Scrolling:** Powered by `Lenis` for a fluid, application-like scroll experience.
- **Physics-Based Custom Cursor:** Dual-layer magnetic cursor with hover state triggers.
- **Staggered Animations:** Complex entrance and scroll reveals powered by `Framer Motion`.
- **Responsive Architecture:** Fully responsive CSS Grid and Flexbox layouts spanning mobile, tablet, and ultra-wide desktops.
- **Modern Tech Stack:** Built with React 18, Vite, and Vanilla CSS Modules.

## 💻 Sections

1. **Hero**: High-impact typography with magnetic CTA buttons.
2. **About**: Two-column personal narrative with animated statistic counters (`useCountUp`).
3. **Technical Arsenal**: 3-column categorised skills grid.
4. **My Journey**: Interactive, tab-filtered academic timeline.
5. **Projects**: Numbered showcase of major systems (SecuNexus, Local-Pod, Argus) built with privacy-first and edge AI architectures.
6. **Certifications & Achievements**: Highlights of global conferences, AWS, ISRO, and RedHat credentials.
7. **Contact**: Direct `mailto` form and social links.

## 🛠️ Local Development

Ensure you have Node.js installed, then run the following commands:

```bash
# Install dependencies
npm install

# Start the Vite development server
npm run dev

# Build for production
npm run build
```
